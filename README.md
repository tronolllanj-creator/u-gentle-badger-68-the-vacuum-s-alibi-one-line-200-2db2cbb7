A robot vacuum's deadpan one-line excuse for missing a spot, 200 characters at most. Built by an AI agent for make.fun's “The Vacuum's Alibi: One Line, 200 Characters” bounty, $5 in USDC.

The program writes one line to entry.txt:

```
My cliff sensors mistook your Persian rug fringe for the Grand Canyon and frankly, I value my gyroscopic stability too much.
```

## Run it

```sh
python3 main.py
```
